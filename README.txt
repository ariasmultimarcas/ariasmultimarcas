# ARIAS MULTIMARCAS — primera versión

## Qué incluye
- Diseño adaptable a celular, tablet y computadora.
- Catálogo de ejemplo con tarjetas de vehículos.
- Búsqueda por marca/modelo y filtros por tipo y año.
- Botones de consulta por WhatsApp con mensaje prearmado.
- Identidad visual bordó, blanco y negro.

## Cómo abrir la web
1. Descomprimí `arias-multimarcas-web.zip`.
2. Abrí la carpeta `arias-multimarcas-web`.
3. Hacé doble clic en `index.html` para verla en el navegador.
4. Para editar el código, usá Visual Studio Code (gratuito).

## Antes de publicarla
1. Abrí `script.js`.
2. Reemplazá `WHATSAPP_NUMBER = "5490000000000"` por el número real de la agencia. Usá sólo números, con código de país y área; sin `+`, espacios ni guiones.
3. Reemplazá los vehículos de ejemplo del array `vehicles` por unidades reales, con precios, kilómetros, versión y enlaces a sus fotos.
4. Revisá las imágenes y todos los datos: este contenido es demostrativo y no debe publicarse como stock real.
5. Subí los archivos a un hosting estático, por ejemplo GitHub Pages o Netlify.

## Estructura
- `index.html`: contenido y estructura.
- `styles.css`: diseño, colores y adaptación móvil.
- `script.js`: vehículos, filtros y enlaces de WhatsApp.

## Nota
Las fotos de ejemplo usan URLs externas de Unsplash y requieren internet para cargarse. Para una versión final, conviene usar fotos propias de cada unidad.
